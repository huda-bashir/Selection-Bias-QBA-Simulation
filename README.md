# Selection Bias Quantitative Bias (QBA) Simulation
This repository contains supplementary material for the manuscript "Using Probabilistic Bias Analysis to Adjust for Selection Bias in Retrospective Case-Control Studies" published in _Insert Journal & DOI here_.

The Selection_Bias_Simulation_Study.R file contains code pertaining to the simulation study. A description of the methods can be found in the supplementary material for as well as the file entitled "Supplement_Using Probabilistic Bias Analysis to Adjust for Selection Bias in Retrospective Case-Control Studies.docx"

The Selection_Bias_Real_Data_Application.R file contains code pertaining to the bias-adjustment for the real data application in the original manuscript.
